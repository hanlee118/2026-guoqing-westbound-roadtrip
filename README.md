# 山河向西 · 2026 国庆自驾决策页

纯静态单页，无构建步骤、无收费 API、无密钥依赖。页面为杭州 / 温州切换、7 日激进版行程、费用估算、勾选进度、打印样式与国庆假期倒计时。

## 本地预览

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173/`（在本目录执行）。

## 资料口径

- 假期日期依据国务院办公厅通知确认：10 月 1 日至 10 月 7 日，共 7 天。
- 高速免费车型、免费时段与计时口径以《重大节假日免收小型客车通行费实施方案》（国发〔2012〕37 号）及 2026 年节前交通运输部门公告为准；页面不把未核验的当年细节写成已确认事实。
- 里程与时长是路线级估算，不是实时导航结果。

页面中的景点视觉为原创 SVG 示意图，避免外部图片版权与热链依赖。
