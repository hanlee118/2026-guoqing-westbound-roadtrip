# 山河向西 · 2026 国庆自驾决策页

纯静态单页，无构建步骤、无收费 API、无密钥依赖。页面为杭州 / 温州切换、7 日激进版行程、费用估算、勾选进度、打印样式与免费窗口倒计时。

## 本地预览

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173/`（在本目录执行）。

## 资料口径

- 2026 年国庆假期：10 月 1 日至 10 月 7 日，共 7 天。
- 免费窗口：10 月 1 日 00:00 至 10 月 7 日 24:00。
- 默认车型：7 座及以下非营运小型客车；封闭式高速以驶离出口收费车道时间为准。
- 里程与时长是路线级估算，不是实时导航结果。

页面中的景点视觉为原创 SVG 示意图，避免外部图片版权与热链依赖。
